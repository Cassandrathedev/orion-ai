# Orion AI
Orion AI is a fully responsive AI SaaS startup landing site built with pure HTML, CSS and JavaScript.

# About
Orion AI is a fictional workflow automation platform. The site is designed to look and feel like a real, funded AI startup - dark premium aesthetic, smooth animations, and a fully working UI across four pages.

# Pages
	•	Home - hero section, features grid, how it works, testimonials, CTA
	•	Pricing - monthly/annual toggle, three pricing tiers, FAQ accordion
	•	About - company story, animated stats counters, team cards, values
	•	Contact - working contact form with success state, contact detail

# Features
	•	Scroll reveal animations using Intersection Observer
	•	Navbar blur effect on scroll
	•	Monthly/Annual pricing toggle
	•	FAQ accordion
	•	Animated stat counters on the About page
	•	Contact form with success feedback
	•	Fully responsive - mobile, tablet, desktop
	•	Hamburger menu for mobile

# Built With
	•	HTML5
	•	CSS3 (Custom Properties, Grid, Flexbox, Animations)
	•	JavaScript (ES6+, Intersection Observer API)
	•	Google Fonts - Syne + Inter
